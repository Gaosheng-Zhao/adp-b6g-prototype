# ADP Transition Prototype

This lightweight prototype visualizes the transition from a wireless communication network to an active Autonomous Digital Population (ADP) in a controlled mobility zone with a relatively stable operational core.

The demo follows the paper's core logic:

```text
Wireless observations
  -> spatial/temporal/communication dependencies
  -> EHC relation structure
  -> recurring pre-action conflicts
  -> Candidate ADP
  -> reasoning items
  -> BS-side wireless resource scheduling
  -> reasoning alignment
  -> Active ADP
```

The visualization separates the two timescales used by the framework:

- Slow organizational epochs (illustrated as approximately 20 s): dependency accumulation, EHC construction, Candidate ADP discovery, and population evolution.
- Fast decision slots (illustrated as below 100 ms): pre-action conflict detection, reasoning-item generation, wireless resource scheduling, and incremental reasoning alignment.

The browser demo is organized as a long-form, three-part walkthrough: slow EHC/Candidate ADP formation, fast reasoning alignment and activation, and cross-timescale coherence maintenance through population operations.

## Run

The repository includes a generated deterministic trace, so the visualization can be opened immediately by double-clicking `index.html`.

To regenerate the trace:

```powershell
python generate_trace.py
```

For local HTTP serving:

```powershell
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Files

- `generate_trace.py`: minimal dependency identification, Candidate ADP discovery, reasoning-item generation, and item scheduling logic.
- `data/trace.js`: deterministic event trace generated by the Python prototype.
- `index.html`, `styles.css`, and `app.js`: dependency-free browser visualization.

The prototype is intentionally small. It demonstrates the paper's causal chain rather than claiming a complete radio-stack implementation.
